# API

Base path: /api/v1

Endpoints:
- GET /health
- GET /system/info
- GET /system/metrics
- GET /apps
- POST /apps/register
- PUT /apps/:id
- DELETE /apps/:id
- POST /apps/discover
- POST /actions/execute
- POST /pairing/confirm
- GET /devices
- DELETE /devices/:id
- GET /settings
- PUT /settings

WebSocket: /ws (authenticated).
